# Deep Learning 从零实现（学习项目）

跟着 [rethink.fun](https://www.rethink.fun/) 的教程，从零基础系统学习深度学习，并用 PyTorch 手写实现经典模型。

## 已实现内容

| 目录 | 内容 |
|---|---|
| `linear-regression/` | 线性回归 |
| `Affine/` | 仿射层 |
| `CNN/` | 卷积神经网络 |
| `ResNet/` | 残差网络 |
| `Attention-RNN/` | 注意力机制 + RNN |
| `sort/` | 序列排序任务 |
| `Transformer/` | Transformer 从零实现 |
| `*.model` / `*.vocab` | 中英文 BPE 分词器 |

## 说明

- 训练好的模型权重（`*.pt`）未上传（见 `.gitignore`），仓库以代码为主；
- 本仓库为学习记录，代码参考 rethink.fun 教程实现，非生产可用。
